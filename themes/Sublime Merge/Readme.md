# Squirrelsong Light Theme for [Sublime Merge](https://www.sublimemerge.com/)

## Installation from GitHub

1. Clone the repository or [download as a ZIP archive](https://github.com/sapegin/squirrelsong/archive/refs/heads/master.zip).
2. Unzip the files.
3. Select **Preferences → Browse Packages** to open your Sublime Merge packages directory.
4. Copy the files from `themes/Sublime Merge` into your Sublime Merge packages directory.
5. Go to **Preferences → Theme…** and select **Squirrelsong Light**.
