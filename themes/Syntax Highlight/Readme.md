# Squirrelsong Light Theme for [Syntax Highlight](https://github.com/sbarex/SourceCodeSyntaxHighlight)

## Installation from GitHub

1. Download [`Squirrelsong Light.theme`](Squirrelsong%20Light.theme).
2. Open the app, then **Colors**.
3. Open **Add** dropdown at the bottom, and choose **Import**.
4. Select `Squirrelsong Light.theme`.
5. Go to **General** tab.
5. Select **Squirrelsong Light** in the **Color scheme/Light** menu.
